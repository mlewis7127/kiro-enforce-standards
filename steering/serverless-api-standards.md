# Serverless API Standards
All serverless API's must be developed using Nodejs and configured using the AWS Serverless Application Model (AWS SAM). All APIs must be deployed in the `us-west-2` (Oregon) region in AWS. Use mcp `awslabs.aws-serverless-mcp-server` for general AWS best practice for serverless deployments.

## Key References

 - **AWS SAM Standards**: Use mcp `awslabs.bedrock-kb-retrieval-mcp-server` to retrieve details on AWS SAM standards to use

 - **Powertools**: Use mcp `powertools` to check for up to date documentation on the AWS Powertools for Lambda
